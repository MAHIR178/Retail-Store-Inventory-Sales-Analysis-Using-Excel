# Retail-Store-Inventory-Sales-Analysis-Using-Excel
Analyzed 73,100 sales and inventory records across 5 stores and 4 regions using Microsoft Excel. The analysis focused on sales trends, inventory levels, and low-stock records. Created interactive dashboards using Pivot Tables, Slicers, and Excel formulas to present key findings and support data-driven analysis.

Note: The original Excel workbook is large, so screenshots of the analysis and dashboard are provided in this repository for reference.
